# GER: Graph-Based Evidence Recovery

Supplementary materials for **Graph-Based Evidence Recovery for Surgical Question Answering**.

**Authors:** Eungjoo Lee, Manglam Srivastav, and Abhimanyu Pandey  
**Affiliation:** The University of Arizona  
**Corresponding author:** eungjoolee@arizona.edu

## Materials

| File | Contents |
| --- | --- |
| [supplementary.pdf](supplementary.pdf) | Source articles and questions, additional answer outcomes, assessment methods, earlier verification results, and statistical definitions. |
| [data/02_Review_Results_72_Items.csv](data/02_Review_Results_72_Items.csv) | Expanded source-assessment checklist: 26 proposition judgments, 36 qualification judgments, and ten coverage checks. |
| [data/03_Original_Template_Completed.csv](data/03_Original_Template_Completed.csv) | Original completed template containing the 26 proposition and ten coverage rows. |
| [data/04_Qualification_Attachment_Map.csv](data/04_Qualification_Attachment_Map.csv) | Mapping of the 36 attached qualifications to their parent propositions, with judgments and supporting quotations. |

The CSV files preserve the supplied assessment records without alteration. They document correspondence with the cited sources; they are not independent clinical validation. The supplementary PDF describes the assessment scope and automated assistance.

These files provide the supplementary material accompanying the manuscript. The remaining evaluation data and code are available upon reasonable request from the corresponding author.
